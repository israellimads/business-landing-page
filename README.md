# 🛒 Business & Local Store Landing Page

Uma Landing Page moderna, leve e 100% responsiva projetada para lojas locais, prestadores de serviços e pequenos comércios. O foco principal é a alta conversão através da integração direta de pedidos via **WhatsApp Web / API**.

---

## 🚀 Demonstração Online
🔗 [Acesse o site em funcionamento aqui](https://israellimads.github.io/business-landing-page/)

---

## 📌 Funcionalidades Principais
- **Layout Responsivo:** Adaptado para celulares, tablets e computadores.
- **Integração com WhatsApp:** Botões de compra pré-configurados com mensagens personalizadas para cada produto.
- **Navegação Smooth Scroll:** Rolagem suave pelos tópicos da página.
- **Menu Mobile Interativo:** Desenvolvido com JS puro.
- **Seção de Prova Social:** Exibição de depoimentos de clientes.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Semântico e estruturado)
- **CSS3** (Flexbox, CSS Grid, Media Queries, variáveis)
- **JavaScript (ES6+)** (Manipulação do DOM e eventos)
- **FontAwesome** (Ícones vetoriais)
